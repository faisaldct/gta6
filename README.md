Neon Harbor: an original open-world crime game — explore a sun-soaked coastal city on foot and by car, steal cars, outrun the harbor police, and run five story missions for the fixer Marlowe Vane. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`.

## How to play

- **WASD / Arrows** — walk and drive
- **Mouse** — aim · **Click / Space** — shoot / handbrake
- **E** — steal / enter a car · **R** — repair at the garage ($80)
- **P** — pause · **M** — mute

Rook is out of the Harbor lockup and in debt to Marlowe Vane. Five jobs stand between Rook and freedom: steal wheels, move hot cargo across town, stop a courier van, and survive a five-star manhunt to the lighthouse. Crimes raise your wanted level; the harbor police answer with foot cops and patrol cars. Progress saves automatically.
